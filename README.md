# Decisões de layout
## Breakpoints utilizados

- 480px → celulares pequenos

- 767px → tablets e celulares grandes

- 1023px → notebooks/desktops

Nas minhas decisões de layout, eu optei por trabalhar com grid e flexbox porque isso me dá controle sobre como os elementos se organizam na tela. Eu quis que cada parte tivesse uma hierarquia clara: títulos em destaque, inputs bem dimensionados e botões com espaçamento suficiente para não parecerem apertados. Também mantive uma paleta de cores neutras (cinza, branco e preto) para dar contraste e deixar o foco no conteúdo, sem poluir a interface.
Outro ponto importante foi a responsividade. Eu defini breakpoints estratégicos para que o layout se adapte a diferentes dispositivos:

- Eu escolhi trabalhar com o sistema mobile-first porque ele me dá mais controle e clareza na construção das telas. Para mim, é muito mais fácil começar pensando em um celular pequeno e depois ir ampliando a estrutura conforme a tela cresce, do que tentar reduzir algo já feito para desktop.

Toda a raiz do meu projeto parte de uma largura mínima de 480px, que representa celulares pequenos. A partir daí, quando a tela aumenta, eu aplico o breakpoint seja ele de 767px ou 1023px, que já cobre tablets, celulares maiores e notebooks/desktops. Essa lógica me permite ir adicionando elementos, ajustando grids e expandindo espaços conforme os exemplos:

# Observações de acessibilidade
 
Eu utilizei o site [Siege Media](https://www.siegemedia.com/contrast-ratio#white-on-black) como referência para calcular a relação de contraste entre cores e garantir que o fundo e o texto tivessem a melhor legibilidade possível. Esse tipo de ferramenta mostra se a combinação atende aos padrões de acessibilidade definidos pelo WCAG (Web Content Accessibility Guidelines), que recomendam contrastes mínimos para textos normais e grandes.

Além disso, para ter certeza prática, eu usei a DevTools do Edge. Com ela, consegui inspecionar os elementos diretamente na página e verificar se o contraste estava adequado. Essa dupla checagem me deu segurança de que as cores escolhidas não apenas funcionam visualmente, mas também cumprem requisitos técnicos de acessibilidade.
